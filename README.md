# SOC Lab Portfolio – Alen Guner

This repository contains hands-on security operations labs focused on alert detection, log analysis, incident investigation, and response workflows. The projects simulate common SOC use cases using Python, Sysmon, threat intelligence, and structured incident reporting.

---

## Featured Projects

| Project | Description |
|--------|--------|
| [AI SOC Copilot](./ai-soc-copilot) | Analyzes SSH authentication logs, detects brute-force activity, maps findings to MITRE ATT&CK T1110, and generates incident reports using the OpenAI API. |
| [Windows Sysmon AI Detection Lab](./windows-sysmon-ai-detection) | Detects suspicious PowerShell execution using Sysmon and generates endpoint investigation reports. |
| [Threat Intelligence Enrichment Lab](./threat-intel-enrichment-lab) | Enriches IP addresses, domains, and file hashes and produces investigation-ready threat intelligence reports. |
| [Phishing Email Analyzer](./phishing-email-analyzer) | Extracts suspicious URLs and social engineering indicators and generates phishing analysis reports. |
| [CloudTrail SOC Pipeline](./cloudtrail-soc-pipeline) | Parses AWS CloudTrail logs to identify suspicious IAM activity and risky API calls. |
| [Brute Force Detection](./brute-force-detection) | Detects repeated failed SSH login attempts from Linux authentication logs. |
